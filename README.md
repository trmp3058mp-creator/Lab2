## Опис проєкту
Адаптивний односторінковий лендінг меблевого каталогу **FurniShop**, спеціалізованого на ергономічних меблях для домашнього кабінету (робочі столи, крісла, стелажі, освітлення).

## Технічні рішення
1. **Відмова від CSS-фреймворків:** верстка виконана на чистому CSS3 із використанням власних семантичних класів для повного контролю над сіткою та відповідності макету Figma.
2. **Шрифти (Google Fonts):**
   - Основний шрифт: `Saira` (відповідає макету Figma).
   - Додаткові шрифти підвалу: `Raleway` та `Inter`.
3. **Побудова сітки:**
   - **Flexbox:** застосовано у шапці сайту (`.topbar-row`), головному екрані (`.hero-layout`), внутрішній структурі карток товарів (`.product-item`) та нижньому рядку підвалу (`.footer-copyright`).
   - **CSS Grid:** застосовано для сітки каталогу товарів (`.catalog-grid`: 1 колонка на мобільному, 3 колонки від `768px`, 4 колонки від `1200px`), плашки статистики (`.metrics-grid`) та колонок навігації у підвалі (`.footer-columns`).
4. **Адаптивна типографіка:** усі розміри шрифтів та відступи задані у `rem` із використанням функції `clamp()` та винесені у змінні `:root`.

6. ## Середовище розробки
- **Node.js:** `v26.13.0`
- **npm:** `11.20.0`
7. ## Структура проєкту
- `index.html` — головна сторінка з маркерами `<!-- cards:start -->` та `<!-- cards:end -->`.
- `src/scss/` — вихідні файли препроцесора Sass:
  - `_variables.scss` — Sass-змінні, CSS custom properties та міксин `@mixin respond-to`.
  - `_header.scss` — стилі навігації та шапки з вкладеністю й амперсандом `&`.
  - `main.scss` — головний файл стилів, який підключає partials через `@use`.
- `css/style.css` — автоматично згенерований і стиснений CSS-файл.
- `data/products.json` — масив даних карток товарів домашнього кабінету (12 позицій).
- `scripts/build-cards.js` — Node.js-скрипт для генерації HTML-карток із JSON та вставки у `index.html`.
- `img/` — графічні ресурси та іконки.

8. ## Перелік команд npm
- `npm install` — встановлення залежностей розробки (`sass`) із `package.json`.
- `npm run scss:build` — одноразова компіляція `src/scss/main.scss` у стиснений `css/style.css` без source map.
- `npm run scss:watch` — режим автоматичного перезбирання стилів при збереженні змін у `.scss` файлах.
- `npm run build:cards` — запуск скрипта `scripts/build-cards.js`, який читає `data/products.json` і вставляє картки в `index.html`.
- `npm run build` — повний цикл збирання проєкту: спочатку генерує картки (`build:cards`), а потім компілює стилі (`scss:build`).
